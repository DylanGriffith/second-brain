## Project Overview

Second Brain is a personal knowledge base with two components:
1. **Python server** (`server/`) - FastAPI app that stores documents in Vespa and serves hybrid search (BM25 + embeddings)
2. **Go indexer** (`indexer/`) - CLI daemon (`sb`) that collects local data and POSTs to the server

## Architecture

```
indexer/ (Go binary: sb)          server/ (FastAPI + Vespa)
  - Bash/psql/chrome/neovim  -->  POST /api/v1/documents
  - Offline queue                  GET /api/v1/search
  - State: ~/.second-brain/        GET /api/v1/status
                                   GET / (web UI)
```

### Running

```bash
cd server
uv run uvicorn second_brain.app:app --reload
```

### Testing

```bash
cd server
SB_VESPA_URL=http://vespa-01:8080 uv run pytest tests/ -v
```

Tests hit a real Vespa instance. Each test session uses a random namespace (`test_{uuid12}`) for isolation, cleaned up after.

### Vespa

- Deploy: `vespa deploy --wait 300 server/vespa/app`
- Schema: `items` with fields: global_id, namespace, url, title, domain, snippet, content, last_seen, embedding (384-dim)
- Ranking profiles: bm25, closeness, hybrid
- Namespace field used for test isolation and future multi-tenancy
- Document URL: `/document/v1/{namespace}/items/docid/{url_encoded_global_id}`
- Search YQL filters on `namespace contains '{ns}'`

## Go Indexer (`indexer/`)

### Structure

```
indexer/
  main.go
  cmd/root.go, run.go, sync.go, status.go
  internal/
    client/     # HTTP client for Python server
    config/     # Config struct, home dir expansion
    queue/      # File-based offline queue (~/.second-brain/queue/)
    state/      # State persistence (~/.second-brain/state.json)
    sources/    # Source interface + bash, psql, chrome, neovim impls
```

### Building

```bash
cd indexer
go build -o sb .
```

### Testing

```bash
cd indexer
go test ./internal/... -v
```

### Source implementations

- **bash/psql**: Resume via last-10-lines anchor in state; SHA256 hash of line as ID
- **chrome**: SQLite cursor on `last_visit_time`; fetches page content with HTML stripping
- **neovim**: Reads `~/.second-brain/neovim-opened-files.log`; ISO timestamp cursor; skips binary files

## Key Design Decisions

- **No background sync in server** - the Go client is the only indexer; server is stateless
- **Namespace isolation** - `namespace` field on documents + Vespa path namespace for test cleanup
- **Offline queue** - Go client queues to `~/.second-brain/queue/*.json` when server is down
- **State file** - `~/.second-brain/state.json` tracks per-source cursors/last-lines
- **Document IDs** - URL-encoded composite keys: `{source_type}:{item_id}`
- **Embeddings** - Generated by Vespa's e5-small-v2-int8 embedder from `title + " " + snippet`
